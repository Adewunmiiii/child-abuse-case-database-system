# Enhanced Database Management System for Child Abuse Cases

Secure web-based platform designed to manage sensitive child abuse case reports while protecting victim identity and ensuring data integrity.

This was my undergraduate thesis project (BSc Computer Science, 4.05/5.0 - Joseph Ayo Babalola University).

## Problem Solved
Child abuse case records are sensitive and need secure storage, controlled access, and confidentiality. This system solves that.

## Key Features
- Anonymous Reporting - victims/witnesses can report without revealing identity
- Role-Based Access Control (RBAC):
    - Admin - Full access & user management
    - Social Worker - View and manage assigned cases
    - Law Enforcement - Secure access to relevant cases
- Secure data storage with MySQL
- Protection of sensitive information & victim privacy
- User authentication & authorization

## Tech Stack
- Backend: PHP
- Database: MySQL
- Frontend: HTML5, JavaScript, Tailwind CSS v4 (offline)
- Other: MS Access (initial design), Database Normalization
